ROAD CONTINUITY REVISION

Changed files
- road_continuity.py: Blender integration. Pure Blender + stdlib runtime.
- road_surface_cache.json: clipped, unioned and terrain-partitioned planar road surfaces.
- road_graph.json: noded XY walking and vehicle graphs.
- road_graph_3d.json: height-projected graph regenerated by the Blender build.
- prepare_road_continuity.py: deterministic geometry preprocessor (Shapely 2.2).
- audit_road_cache.py: independent planar area and terrain partition audit.
- test_road_module.py: standalone actual-Blender interior-sample test, no full scene export.
- verify_road_before.py: before-state interior-sample test (run against an archived original blend, not the revised blend).

Integration
Replace only the old roadfeatures/OSM road loop with:
from road_continuity import build_continuous_roads
roadfeatures=build_continuous_roads(features,built,height,Mesh,roadcol,asphalt,pave,nav,P)

The full model build remains owned by build_campus.py. Its exact terrain grid must
remain 5m, origin(-490,-1120), diagonal southwest-to-northeast. Re-preprocessing
and integration changes are required if the terrain grid changes.

Reproduce
1. Install Shapely 2.2 for system Python (NOT required for Blender).
   Option: python -m pip install shapely==2.2.0 --target campus/vendor
2. python campus/prepare_road_continuity.py
3. python campus/audit_road_cache.py
4. blender -b --python campus/test_road_module.py
5. Build the full model via build_campus.py and run independent integrated QA.

Verified standalone result
Before: 126,616 interior samples; 533 below terrain; minimum clearance -0.952635m.
After: 152,320 interior samples; 0 below terrain; 0 degenerate faces;
       clearance 0.294678m to 0.295116m.
The new faces are clipped to exactly the same terrain triangles, so slopes cannot
poke through a road face between edge vertices. Multiple-way junctions and width
changes are unioned, preventing cracks and overlapping coplanar asphalt faces.
Tiny numerical slivers below 0.00001m2 are omitted; Blender float32 degeneracies
are filtered. Their total area is below 0.0001m2, not a navigable gap.

Mapped connectivity
286 source ways retained. No invented centerlines or proximity bridges.
Old rectangular main-campus omission skipped 2,207.017m of source centerlines.
New rectangular omission: 0m. This measures OSM-way length, not unique asphalt area.
Mapped-building clearance exclusions total 9.9m of centerline across ways.
Vehicle graph: 942 nodes, one connected component.
Walking graph: components of 1536, 8, and 2 nodes. Source-isolated pedestrian
sections and dead ends are intentionally not joined by made-up paths.
Graphs are undirected geometric navigation graphs, not legal-road routing.
Access/oneway/source metadata is supplied per edge. Default widths are estimates.

Scope and limits
Mapped OSM footprints are clipped from road paving. Unmapped/approximate building
masses need final integrated-model collision QA. Original near-main SITE road
approximations require removal to avoid duplicate overlapping roads; keep the
facade apron/parking and rear service parking. Final integrated QA and renders
are produced separately and must not be replaced by this standalone test.

Evidence PNGs show only the OSM-road layer before/after, with pre-existing SITE
roads omitted in BOTH panels. They are geometry diagrams, not scene renders.
