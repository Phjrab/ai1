# College expansion reference pack

Five main college buildings verified against the official campus tour. All five exist in source OSM geometry but were intentionally excluded from the existing 56-building model, so inclusion adds five masses with no replacement needed. Suppress obsolete grouped map markers 169/170 to avoid double-counting.

Official campus tour: https://www.cst.ac.kr/page/?mn=952&site=basic

Official photos: https://computer.cst.ac.kr/pages/department/comm_img/position_img0.jpg through position_img4.jpg. Files photo_0..4.jpg respectively show HQ, Buildings 1, 2, 3, 4. All inspected. The source labels are visible on the photos except Building 1, whose official department location page identifies it.

The illustrated map and cam_0..4 cutouts are layout/silhouette references; actual photos override their stylized colors. Photos are reference only, not redistributed game textures. Dates of photography not stated.

Public directory establishes above-ground floors 5/7/5/5/3 respectively, with B1 for Buildings 3 and 4. Use approximate floor heights and do not claim surveyed dimensions/interior accuracy.

Road 470872959 (조선이공대길) and branch 470872992 already exist in included geometry; preserve them. Internal service ways, parking and planting traces included in manifest. No roads require duplicate extrusion.

No hospital, nursing college, or Chosun University building is classified as a CST building.
