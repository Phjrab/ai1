# 조선대학교 캠퍼스 산책 · Three.js

독립된 브라우저 게임 프로젝트입니다. 원본 본관 모델링 프로젝트를 수정하거나 대체하지 않습니다.

## 실행

`dist` 폴더를 HTTP 서버로 제공합니다. 예: `python3 -m http.server 8173 --directory dist`

브라우저에서 해당 서버 주소로 접속합니다. WebGL 2와 JavaScript가 필요합니다. GLB/모듈을 읽으므로 index.html을 파일로 직접 열지 마세요. 게임 실행에는 npm이나 외부 CDN이 필요하지 않습니다. Three.js 0.180.0 및 필요한 모듈을 동봉했습니다.

## 조작

- WASD 또는 방향키: 이동 / 운전
- 마우스: 시선. Esc: 마우스 잠금 해제. 잠금이 어려운 환경에서는 화면 드래그 가능
- Shift: 달리기
- E: 가까운 NPC 대화, 노란색 또는 하늘색 탐험 차량 탑승 / 하차
- Space: 차량 브레이크. 속도를 줄여야 하차할 수 있음
- 처음 위치: 본관 앞길로 안전하게 복귀
- 장소 메뉴: 50개 장소의 안전한 보행 위치로 이동. 장애물이 있으면 12m 이내에서 인접 안전 위치 선택
- 모바일: 왼쪽 조이스틱 이동, 오른쪽 화면 드래그 시선, 상호작용 버튼. 실제 기기 테스트는 미실시

## 모델과 사실성

별도 건축 모델링 산출물의 최종 GLB를 복사하여 사용했습니다. 본관 전체 19개 박공, 둥근 양쪽 부속동, 1층 복도와 세 출입구를 포함합니다. 확장 캠퍼스에는 67개 건축 매스와 50개 공식 명칭 목적지가 포함되며, IT융합대학·사회과학/사범대학·미술대학·학생회관·서석홀·제1/2공학관·글로벌하우스·백학학사·중앙도서관을 장소 메뉴에서 선택할 수 있습니다. glTF 좌표는 원본 Blender (x,y,z)를 Three.js (x,z,-y)로 변환합니다. 본관 중앙 정면은 x0,z0이며 바닥 높이는 0.15m입니다.

외형은 공개된 사진을 기반으로 한 재구성으로, 실측 BIM이나 검증된 도면이 아닙니다. 내부 배치는 미확인 부분을 포함한 개념 모델입니다. 실제 제공된 1층 복도만 탐험할 수 있고, 상층 순환·교실 출입은 제공하지 않습니다. NPC, 대화, 탐험 차량은 게임용 창작입니다. 캠퍼스 지형, 식생, 주차 위치도 개략적입니다.

## 기술 구성

- `dist/game.js`: Three.js 렌더링, GLB 로딩, 인스턴싱, 동일 재질 정적 메시 병합, 플레이어·차량·NPC 상태, 충돌 및 터치 조작
- `dist/assets/building.glb`: 최종 본관 모델 복사본
- `dist/assets/campus.glb`: 최종 전체 캠퍼스 모델의 Meshopt 압축 사본
- `dist/world-config.js`: 도로·안전 도착 위치·충돌 프록시·분산 NPC/차량 배치
- `data/campus-navigation.json`: OSM 및 공식 캠퍼스 지도 기반 공간 데이터
- `dist/vendor`: Three.js MIT 배포본. Octree는 대형 건축 장면에서 메모리 폭증을 방지하기 위해 최대 깊이 6, 리프 삼각형 기준 32로 제한한 작은 패치 포함
- 건물 충돌은 지상 보행에 필요한 삼각형만 추출하고, 수목 줄기 및 주차 차량에는 간단한 충돌 프록시 사용
- 외부 계정, 데이터 저장 또는 사용자 추적 없음
- 캠퍼스 원본 GLB 약 72MB를 약 15MB로 압축. 16비트 위치 양자화에 따른 최대 수cm 수준의 위치 변화가 가능하며 무손실이라고 주장하지 않습니다. 렌더링용 원본 형태와 세부 요소를 유지하며, 웹용 압축 사본은 건축 원본을 변경하지 않습니다.

## 검증 범위

`npm install` 후 `npm test`를 실행하면 실제 GLB 파싱·충돌 구조 생성과 게임의 동일 이동·상호작용 코드를 테스트합니다. 렌더러와 DOM은 모의 객체로 대체한 소스 통합 테스트이며, 실제 브라우저 렌더링 테스트가 아닙니다.

검증: 50개 목적지 안전 도착, 19명 NPC·11대 탐험 차량 배치, 출입구 진입, 복도 벽·정면 벽 충돌, 지형 높이, NPC 대화, 차량 탑승·주행·제동·하차, 초기 위치 복구. 결과는 `tests/simulation-results.json`에 기록됩니다.

현재 실행 환경에서 Chromium 실행에 필요한 Unix 소켓 접근이 제한되고, 클라우드 브라우저의 로컬 미리보기 접근도 차단되어 데스크톱·모바일 화면 렌더링 및 실기기 터치 검증은 완료하지 못했습니다. 특히 모바일 GPU 성능은 기기에 따라 달라질 수 있습니다.

## 라이선스

게임 코드, NPC 및 차량 형상은 이 프로젝트를 위해 제작했습니다. 건축·캠퍼스 형상은 별도 요청에 따라 제작한 모델입니다. Three.js MIT 라이선스는 `dist/vendor/THREE-LICENSE.txt`에 있습니다. 조선대학교의 공식 서비스 또는 공식 도면을 의미하지 않습니다.

## 모바일 기본 품질

터치 장치에서는 픽셀 비율을 1.15로 제한하고 실시간 그림자를 끕니다. 건축물 형상은 유지하며, 먼 나무와 주차 차량 인스턴스만 거리별로 숨깁니다. 모바일의 달리기 버튼은 운전 중 브레이크로 바뀝니다. 실제 iPhone 성능이나 화면 품질은 테스트하지 못했습니다.

치과대학 연구동 목적지는 교육동과 공유하는 모델 건물로 표시합니다. 태양에너지실증연구단지는 확인된 지도 핀 주변의 대표 위치이며, 별도의 정밀 건물 복원을 의미하지 않습니다. 장소 메뉴 50개는 50개의 서로 다른 정밀 건물 모델을 뜻하지 않습니다.

확장 범위에는 조선이공대학교 본관·1호관·2호관·3호관·4호관과 조선대학교병원 외관도 포함합니다. 체육대학과 자연과학관도 각각 목적지로 선택할 수 있습니다. 병원·추가 대학 건물 내부는 복원하지 않았습니다.

## 모델 업데이트 재현

최종 건축 작업에서 내보낸 campus.glb를 준비한 뒤 `node scripts/compress-campus.mjs INPUT.glb dist/assets/campus.glb`를 실행합니다. 같은 좌표계의 navigation.json이 담긴 폴더를 `python3 scripts/integrate-campus.py CAMPUS_DIRECTORY`로 변환하고, `npm test`로 도착 위치와 상호작용을 확인하세요. 본관 geometry.json은 해당 폴더와 나란한 building 폴더에서 읽습니다.

## 공개 저장소에서 모델 갱신

기본 폴더 구성은 `architecture/`와 `game/`가 나란히 있는 구조입니다. 다른 위치라면 CHOSUN_MODEL_ROOT 환경변수로 건축 프로젝트 루트를 지정합니다. 예: `CHOSUN_MODEL_ROOT=../architecture python3 scripts/integrate-campus.py` 및 `CHOSUN_MODEL_ROOT=../architecture python3 scripts/integrate-transit.py`. 노선 근거 데이터는 기본적으로 `data/shuttle-sources.json`을 읽으며 TRANSIT_REFERENCE_PATH로 바꿀 수 있습니다.

공개용 소스 ZIP은 커밋 후 `python3 scripts/export-source.py OUTPUT.zip`으로 만듭니다. 비공개 Sites 식별자가 담긴 `.openai/`, Git 메타데이터, 로컬 런타임 및 환경 설정 파일은 포함하지 않습니다. 정적 게임 실행에는 Sites 메타데이터가 필요하지 않습니다.

## 운행 셔틀과 정류장

공식 안내에 나타난 설립기념탑 → 미대 → 중앙도서관 → 공대 제2공학관 → 법대·경상대 → 본관 북쪽 → 학생회관 순서를 바탕으로, 모델의 연결된 도로에 주행선을 재구성했습니다. 정확한 실제 정차 좌표나 실시간 운행을 재현한다고 주장하지 않습니다.

게임은 셔틀 2대, 최대 약 21.6 km/h, 정류장당 10초 정차로 동작합니다. 명목 운행 간격은 약 4분이며 사람이나 차량 앞에서 안전 대기하면 지연됩니다. E키 탑승 대상은 탐험 승용차입니다. 셔틀은 자동 순환 운행을 시연합니다.

버스의 흰 상부·파란 하부 도색은 2025년 교지의 전면/좌측 사진과 2026년 교내 신문의 후면 사진을 참고했습니다. 우측은 대칭 추정입니다. 참고 사진은 게임이나 소스에 포함하지 않았습니다. 기념탑·사범대 쉼터는 각각 확인된 사진 형상을 참고했고 설치 위치와 치수는 근사치입니다. 사범대 쉼터는 별도 노선 시설로, 이 7개 정류장 시연 순환에는 포함되지 않습니다.

건축 모델에 놓인 정적 전시 버스는 게임에서 제외하고 같은 차량 자산을 움직입니다. 셔틀 통행을 가로막는 장식 주차 차량은 게임에서만 제외할 수 있습니다. 원본 건축 파일의 배치는 유지됩니다. 탐험 승용차의 수는 유지하며 주차 위치만 통행에 맞춰 조정합니다.

`node tests/shuttle.mjs`는 정차·출발·감속·안전 대기 단위 테스트입니다. `node tests/shuttle-live.mjs`는 실제 게임 업데이트와 장애물 검사 함수로 20분을 시뮬레이션합니다. 실제 GPU·브라우저·iPhone 성능 측정은 아닙니다.

## 최종 계단·지형·재질

435개 명시적 보행면(사진 참고 계단 220개, 추정 고도 연결면 215개)을 포함합니다. 추정 연결은 실제 시설의 실측 복원이 아닙니다. 바닥은 모델의 실제 충돌 면에서 계산하며, 지형 격자 값으로 잘려 있는 계단 위를 다시 덮지 않습니다. 고도는 공개 지형 자료의 경향과 도로·건물 패드 보정을 조합한 근사값입니다.

116개 재질 정의를 원본 이름에 따라 적용했습니다. 웹에서는 기본 색상·거칠기·금속성의 상수 PBR 폴백을 사용합니다. Blender 절차적 벽돌·미세 표면·수목 색 편차 전체를 그대로 재현하는 것은 아닙니다. 본관과 캠퍼스는 Meshopt 압축하며 버스 휠/조향 피벗은 보존합니다.

추가 회귀 명령: `node tests/vehicle-grounding.mjs`, `node tests/walkable-paths.mjs`, `node tests/transit-integration.mjs`.

PBR 폴백을 함께 적용하려면 `node scripts/compress-campus.mjs INPUT.glb dist/assets/campus.glb data/game-materials.json`을 사용합니다. 본관에도 같은 방식으로 적용하고, 버스는 `--no-compress`로 원래 피벗 구조를 보존할 수 있습니다. `integrate-transit.py`는 버스 원본을 복사하므로 버스 재질 적용은 통합 뒤 실행하세요. 최종 파일의 해시는 `CHOSUN_MODEL_ROOT=../architecture python3 scripts/record-provenance.py`로 기록합니다. 자동 경로 생성은 최초 재구성용이며, 검토를 마친 최신 `campus/transit_placements.json`이 있으면 그것을 우선 사용합니다.

`node tests/actors.mjs`는 NPC 19명의 시간별 이동과 차량 11대의 탑승·주행·제동·하차를 검증합니다.
