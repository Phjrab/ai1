# 조선대학교 캠퍼스 산책 · Three.js

Blender 캠퍼스 모델의 웹용 사본을 사용하는 독립 브라우저 게임입니다. 공식 서비스나 실측 BIM이 아닙니다. 모델·웹 자산·메타데이터의 정확한 해시는 `MODEL_PROVENANCE.json`에 기록합니다.

## 실행과 조작

`python3 -m http.server 8173 --directory dist`를 실행하고 브라우저에서 해당 서버에 접속하세요. WebGL 2가 필요합니다. GLB와 모듈을 읽으므로 `index.html`을 파일로 직접 열지 마세요. 실행 자산과 Three.js 0.180.0을 동봉하여 외부 CDN이나 npm 없이 정적 서버로 실행할 수 있습니다.

- WASD / 방향키: 걷기, 차량 가속·후진·조향
- 마우스 / 화면 드래그: 시선, Esc: 마우스 잠금 해제
- Shift: 달리기, Space: 차량 브레이크
- E: 가까운 NPC와 대화, 탐험 승용차 탑승·하차. 정차 후 안전한 옆 공간에서 하차
- 장소 메뉴: 건물 주변 안전 도착 위치, IT 별관 옥상과 휴게공간
- 처음 위치: 본관 앞길로 복귀
- 모바일: 왼쪽 조이스틱, 오른쪽 시선 드래그, 상호작용 버튼. 달리기 버튼은 운전 중 브레이크로 전환

기존 탐험 차량 11대, NPC 19명, 자동운행 시연 셔틀 2대를 유지합니다. 셔틀은 E키 탑승 대상이 아닙니다.

## 모델과 사실성

기존 캠퍼스 목록 69개와 67개 건축 매스, 기존 50개 명칭 목적지를 기반으로 외관, 재질, 지형 접지와 도로·보행 접근을 보강했습니다. 부속 학교 2곳과 연결 도로도 추가했습니다. IT융합대학, 미술대학, 법과대학, 체육대학, 병원 외관을 개별 보강했습니다. 추가된 IT 옥상·휴게공간 목적지는 같은 건물의 다른 높이 공간입니다. 목적지 수를 서로 다른 정밀 건물 수로 해석하지 마세요.

- 본관: 기존 19개 박공, 둥근 양쪽 부속동, 1층 복도와 세 출입구
- 주차빌딩: 사진을 참고한 지상 3층과 옥상, 총 4개 주차 레벨. 85대의 장식 주차 차량, 3개 층간 경사로와 계단 연결. 주차 차량은 탑승할 수 없으며 높이별 충돌을 적용
- IT: 솔마루에서 올라오는 도로의 구름다리, 지도에 확인된 북측 출입문 두 곳, 접합층 휴게공간의 원형 벤치 테이블 6개, 별관 옥상 연결
- 공공 공간: 장미원, 극장, 운동장 둘레 트랙과 골대 4개, 장지연 분수와 청람교, 정문과 열린 정산 차로
- 그 밖의 건물: 확인된 외부 출입문과 접근 경로만 반영. 자료가 없는 내부를 임의로 개방하지 않음

사진·공개 지도와 사용자의 현장 설명을 참고한 근사 재구성입니다. 주차장 내부 배치, 경사로·계단 위치와 치수, IT 휴게공간의 치수·가구 배열·재료, 미확인 파사드와 지형 고도는 추정입니다. 실제 시설의 접근성·안전성·피난 동선이나 현재 주차 가능 여부를 보증하지 않습니다. NPC, 대화와 탐험 승용차는 게임용 창작입니다.

Blender XYZ는 Three.js X,Z,-Y로 변환합니다. 본관 중앙 정면은 x0,z0이며 바닥 높이는 약 0.15m입니다. 치과대학 연구동 목적지는 교육동과 공유하는 모델 건물로 표시하고, 태양에너지실증연구단지는 지도 핀 주변 대표 위치입니다.

## 웹용 표현과 충돌

웹 자산에는 Blender 재질 이름에 대응하는 기본 색·거칠기·금속성·상수 발광의 PBR 폴백을 적용합니다. Blender 절차적 미세 표면 전체나 렌더 전용 개별 잎 수관은 포함하지 않습니다. 게임 나무는 기존 인스턴스형 간소 수관에 새 잎 색상과 부드러운 노멀을 적용합니다. 원본 1,259그루, 중앙 55그루와 추가 녹지 900그루를 합쳐 2,214그루입니다. 보도블록은 원래 미터 단위 UV와 기본색·거칠기·노멀 이미지의 PBR 연결을 보존합니다.

재빌드 파이프라인은 건축 세부를 Meshopt 및 16비트 위치 양자화로 압축합니다. 지형·도로·보행면·주차장 주행면은 작은 경계 틈이나 계단 높이 오류를 막기 위해 원본 Float32 위치를 유지하고 Meshopt로 인코딩합니다. 원본 주차 차량과 나무의 위치·변환도 배치 메타데이터와 일치하도록 보존합니다. 웹 자산 전체를 무손실이라고 주장하지 않습니다. 압축은 별도 사본에 적용하여 원본 Blender 파일을 변경하지 않습니다.

바닥 높이는 실제 내보낸 삼각형에서 구합니다. 주차장 접지는 이전 바닥 높이 주변을 검사하여 위층으로 순간 이동하지 않도록 하고, 주차 차량·기둥·난간은 높이별 충돌을 사용합니다. 원본 장식 차량 117대도 실제 메시에서 추출한 방향·높이별 충돌 상자를 사용합니다. 조향은 캠퍼스 전 구역에 같은 bicycle model을 사용합니다. 게임 차량의 축거 2.70m·윤거 1.84m와 저속 최대 앞바퀴 조향각 35°로 계산하며, 속도 2–8m/s에서 조향 한계를 부드럽게 줄입니다. 최대 저속 조향의 차체 중심 반경은 약 4.09m, 바깥 앞바퀴 중심 반경은 약 5.49m입니다. 35°는 게임 설정값이며 특정 실차의 실측 사양이 아닙니다. 차량 카메라는 양면 벽·천장 충돌을 확인하여 시점 거리를 줄입니다. IT 보행 충돌 예외는 지정된 옥상·다리·실내 다각형과 높이에 한정합니다. 연못 물 영역은 들어갈 수 없으며 실제 청람교 높이의 보행만 허용합니다.

같은 재질의 정적 메시를 병합하고 나무·주차 차량을 인스턴싱합니다. 터치 장치에서는 픽셀 비율을 1.15로 제한하고 실시간 그림자를 끄며 먼 나무와 차량을 숨깁니다. Octree는 대형 장면 메모리를 위해 최대 깊이 6, 리프 삼각형 기준 32로 제한했습니다.

## 셔틀

공식 안내의 설립기념탑 → 미대 → 중앙도서관 → 제2공학관 → 법대·경상대 → 본관 북쪽 → 학생회관 순서를 모델 도로에 맞게 재구성했습니다. 정확한 실제 정차 좌표·노선·실시간 시간표가 아닙니다. 게임 셔틀 2대는 최대 약 21.6km/h, 정류장당 10초 정차, 사람·차량 앞에서 대기합니다. 종점 회차 동선 미확인으로 반복 순환 미구현입니다. 버스는 기존 시작 지점에서 출발해 남은 정류장을 거쳐 종점에서 정차하며, 앞 버스가 있으면 안전 간격을 두고 대기합니다. 게임을 새로 시작하면 초기 운행을 다시 볼 수 있습니다.

바퀴와 허브는 실제 노면에 맞춰 제한된 범위에서 함께 움직입니다. 실제 a1/export2 검사39,610 이동 자세에서 지지 누락 없이 차체와 노선이 연속 이동했고, 최대1.04cm 타이어 관통과20ms 프레임당17.19cm 바퀴 보정 변화가 남았습니다. 최종 모델에서는 이 노면·차량 형상이 그대로임을 결속해 같은 한계로 보존합니다. 고정 검은 휠아치 원판의 최대6.76cm 수치상 지면 교차(각 버스2,719정적자세 중127자세)도 별도로 기록합니다. 고급 차량 동역학이나 GPU 화면 검증을 뜻하지 않습니다.

병원 쪽 시내 정류장 1149는 실제 모델 보도와 공용 진입마당을 통해 병원에 연결됩니다. 반대편 1150은 같은 편 보도만 구현했으며 확인되지 않은 횡단 연결은 제공하지 않습니다. 교내 셔틀과 시내버스 정류장은 별도로 표시합니다. 셔틀은 기존 도로 중심선을 따르므로 연석 정밀 접근이나 탑승 동작은 구현하지 않았습니다.

버스 도색은 2025년 교지 전면·좌측 사진과 2026년 교내 신문 후면 사진을 참고했고 우측은 대칭 추정입니다. 기념탑·사범대 쉼터도 사진을 참고한 근사 형상입니다. 사범대 쉼터는 시연 운행의 정류장이 아닙니다. 참고 사진 원본은 게임에 포함하지 않습니다. 원본 정적 전시 버스는 게임에서 제외하고 움직이는 버스 자산을 사용합니다.

## 검증과 제한

납품 파일의 무결성과 실제 완료한 검사 증거는 `npm run verify:release`로 읽기 전용 확인합니다. 정상 납품본에서는 PASS와 종료코드0을 기대합니다. 이 명령은 새 물리 시뮬레이션이나 브라우저를 실행하지 않습니다.

`npm ci --ignore-scripts` 후 `npm run test:all`은 전체 수치 회귀를 새로 실행하는 긴 명령입니다. 실제 GLB 로더·충돌 구조·게임 이동 함수를 사용하며 DOM과 렌더러만 모의 객체로 바꿉니다. 필수 동작과 아래 한계의 측정 경계를 모두 만족해야 통과합니다. 이번 최종 마감은 전체 명령의 단일 재실행이 아니라, 최종 인덱스에 명시한 기존 완료 검사와 기하 불변 증거, 영향 구간 재검사를 결속했습니다. 기본 `npm test`는 핵심 통합 검사입니다.

421은 실제4방향 완주와 차체·허브·지지 통과를 유지하지만 타이어 측면27/208자세에서 최대44.444251mm의 보수적 겹침 상한이 있습니다. 정산소 lane0은 실제 타이어 접촉 0을 요구합니다. 학교175 역방향의 두 타이어 면 접촉 상한은 5.45/7.48mm입니다. 정확한 타이어·유한 노면 삼각형·발생자세·횟수·개별 깊이 경계만 알려진 시각 한계로 분류하며, 이보다 커지거나 새 몸체/허브/지지/통행 실패가 생기면 집계 검사가 실패합니다. 건물142부근의 필수 중심주행은 통과했지만 선택적±0.3m 편심 진단6건은 실제 경계에 닿습니다.

`npm run test:site-strict`는 모든 타이어 접촉까지 실패로 세는 별도 진단입니다. 보존된 한계 때문에 종료코드1을 기대하며 릴리스 판정 명령과 구분합니다. 원 strict 실패 결과는 수정하지 않고 보존합니다. 나무의 경사지 매립은 동결된 개별9점 식재 계약의 예상 깊이와0.1mm 이내로 대조하며, 의도된 매립106개를 부양 오류와 구분합니다. 양수 부양·잘못된 좌표·지원누락은 계속 실패합니다. `npm run test:closeout`은 원래17개 대상, 물 진입2제약과 학교175 정방향을 합한20항목을 다시 실행합니다.

검사 범위: 목적지 도착, NPC·탐험 차량 수와 상호작용, 걷기·주행·제동·하차, 셔틀 정차·안전 대기·종점 정차 유지, 차량 바퀴 접지, 보행면과 내보낸 표면의 높이 일치, 다층 주차장 경사로·계단 이동, 차체·천장·카메라 충돌, IT 다리·출입문·휴게공간·테이블 접근, 원본 정밀 보행 위치의 압축 왕복 보존, 소스 패키징입니다. 각 결과는 `tests/*results.json`에 기록합니다. 납품본의 실제 완료 검사와 해시는 `tests/FINAL_VALIDATION.json`, 실행 파일 해시는 `dist/release-manifest.json`에서 확인합니다. 과거 입력의 실패·진단 결과는 별도 이력으로 보존하며 최종 통과로 합산하지 않습니다.

실제 WebGL 화면, GPU 속도와 iPhone 터치·성능 검증은 완료하지 못했습니다. 로컬 Chromium 실행은 환경의 소켓 제한으로 차단되었고, 기존 비공개 Site는 클라우드 브라우저에서 소유자 로그인 화면까지만 확인되었습니다. 수치 시뮬레이션 결과를 실제 기기 검증으로 해석하지 마세요.

## 재현과 파일 구성

- `dist/`: 정적 실행 파일, GLB, 동봉 Three.js
- `data/`: 원본 좌표계의 내비게이션·근거·통합 메타데이터
- `scripts/build-realism.mjs`: 출처 해시 검증 → 재질·고도·접근 계약 통합 → 압축 → 실제 바닥 접지 → 해시 기록 → 전체 회귀
- `MODEL_PROVENANCE.json`: 원본/웹 자산·메타데이터·런타임 코드의 SHA256과 개수

기본 저장소 구조는 `architecture/`, `realism_v2/`, `game/`가 나란히 있습니다. 최종 네이티브 내보내기와 연결 메타데이터가 준비되면 `npm run build:model`로 재현합니다. 다른 위치는 `CHOSUN_MODEL_ROOT`와 `CHOSUN_REALISM_ROOT`로 지정합니다. 이번 최종본은 정류장 실물 컬렉션까지 포함한 `realism_v2/game_export_supported_surfaces` 내보내기를 사용하므로, 재빌드할 때 `CHOSUN_GAME_EXPORT_ROOT`를 그 디렉터리로 지정해야 합니다. 내보내기 manifest가 네이티브·모듈·연결 메타데이터의 해시를 모두 검증하므로 서로 다른 모델 단계의 파일을 섞지 마세요.

`npm test`와 `npm run serve`는 시작 전에 실행 자산 해시를 확인합니다. 수정된 GLB를 예전 자산으로 덮어쓰지 않습니다. 누락된 파일만 같은 해시의 저장소 자산 조각에서 복원할 수 있습니다.

`python3 scripts/export-source.py OUTPUT.zip`은 실행 GLB·코드·데이터·테스트·SHA256 목록을 포함한 독립 소스 ZIP을 만듭니다. 동일 파일 상태에서 동일 ZIP 바이트가 생성됩니다. `.openai/`, Git 메타데이터, 로컬 런타임, 환경 설정과 의존성 폴더는 제외합니다. ZIP은 부모 건축 저장소 없이 정적 실행할 수 있으며, 원본 모델 재생성에는 별도 모델 소스가 필요합니다.
